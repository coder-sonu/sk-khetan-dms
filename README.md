# Sk Khetan Group — Fleet Management (V12)

Phase 10 adds mobile-first daily operations to the V9 fleet DMS.

## Included
- 339 source Excel records / 336 unique Vehicle Numbers preloaded
- Mobile-friendly Daily Entry with validation and duplicate protection
- Vehicle Master search
- Vehicle 360
- Breakdown open/close + camera/photo upload
- Service due data
- Dashboard + diesel analytics
- Missing daily-entry checker
- MIS CSV exports and backup
- Existing role-based login and audit trail

## Run on Windows
Double-click `run.bat`, then open `http://localhost:8000`.
Default login: `admin` / `admin123`.

Change the admin password and `DMS_SECRET_KEY` before production use.
